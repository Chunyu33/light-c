# LightC

LightC 是一款 Windows 桌面工具，提供安全垃圾清理、磁盘分析和系统维护功能，使用 React、TypeScript、Rust 和 Tauri 构建。

[English](README.md)

## 主要功能

- **垃圾清理**：支持快速扫描和深度扫描，覆盖临时文件、传递优化文件、缩略图、DirectX 着色器缓存及指定的 Defender 可重建缓存。
- **大文件清理**：按磁盘扫描占用空间较大的文件，提供风险提示、选择控制和安全删除反馈。
- **社交软件专清**：分类查看微信、QQ、钉钉、飞书等支持的软件缓存，确认后再执行清理。
- **系统瘦身**：查看可选的 Windows 系统组件和节省空间的系统设置，执行前提供安全提示；支持在 Windows 搜索索引数据库（Windows.db）异常膨胀时一键重建。
- **旧驱动清理**：识别未使用的第三方驱动包，保护当前正在使用的驱动，并支持备份与恢复流程。
- **卸载残留**：基于置信度结果，从常见位置识别已卸载程序留下的文件夹和注册表残留。
- **注册表冗余**：检测孤立的注册表引用，支持带备份的清理和操作结果反馈。
- **右键菜单清理**：检查失效的右键菜单项，移除不再需要的外壳集成。
- **大目录分析**：分析目录空间占用，逐级定位大目录，并清理支持的临时缓存。
- **磁盘变化分析**：对比磁盘快照，定位一段时间内发生变化的文件和目录。
- **外壳图标管理**：管理“此电脑”中的第三方外壳图标，支持注册表/ACL 备份、恢复和防复活保护。
- **AI 模型空间**：分析本机模型、LoRA、Embedding 及相关缓存占用，并可删除选中的模型数据。
- **多语言界面**：支持简体中文、繁体中文、英语和日语，模块页面、扫描阶段、设置项及稳定后端标签会随语言统一显示。

## 环境要求

- Windows 10 或更高版本。
- Node.js 20.19+ 和 npm。
- Rust 工具链及 Tauri 2 所需环境。

## 开发

```bash
npm install
npm run dev
npm run build
npm run tauri dev
```

## 便携模式

将 `LightC.portable.json` 放在可执行文件旁边。启用后，LightC 会把配置、本地数据和 WebView 数据保存到可执行文件旁边，而不是默认的用户目录。

## 安全说明

- LightC 不会扫描或删除 Windows Defender 根目录、隔离区、定义更新、平台数据及其他受保护的 Defender 数据。
- Defender 清理仅限可重建的 `LocalCopy` 和 `Support` 目录。
- System32 清理仅限明确支持的 DirectX 着色器缓存路径。
- 部分文件需要管理员权限或重启系统，可能会以“未立即完成”状态保留在结果中。
- 执行永久清理前请检查已选项目，并备份重要数据。

## 如何提交 Issue

提交前请先搜索已有 Issue，并尽量做到一个 Issue 只描述一个问题，标题清晰、内容基于事实。可以参考 [《提问的智慧》](https://www.catb.org/esr/faqs/smart-questions.html) 的核心原则：先提供足够上下文，再提出明确问题。

- **Bug 必须提供**：详细复现步骤、预期行为、实际行为、LightC 版本、Windows 版本、当前界面语言，以及相关日志或截图。
- 尽量提供最小可复现案例；发布日志和截图前，请遮盖个人路径、用户名、令牌及其他敏感信息。
- **功能建议**请说明要解决的问题和期望结果，不要只要求采用某一种实现方式。
- 请保持简洁、礼貌并接受必要的追问。避免臆测、辱骂或命令式表达；有上下文、有证据的描述更容易得到准确处理。
- 低质量的 Issue（如傲慢质问、纯抱怨、无上下文、无复现步骤）不会被处理。
